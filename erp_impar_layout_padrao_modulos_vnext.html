layout padrão para todos os módulos

Um shell só, muitas funcionalidades.

Este arquivo resume a anatomia ideal das páginas internas do ERP ÍMPAR. A ideia é padronizar cabeçalho, filtros, KPIs, tabelas, formulários e ações para que todos os módulos conversem entre si e o usuário não precise reaprender a interface a cada tela.

1. shell fixosidebar, topbar e rodapé operacional sempre previsíveis
2. bloco de contextohero curto com status, headline e ações rápidas
3. densidade controladamódulo complexo continua legível porque o layout segura a organização
